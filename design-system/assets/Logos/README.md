# Logos

The Earmark mark is a label tag with a camwood eyelet. In the app, prefer the `Logo` component, which follows the theme; use these files everywhere else (favicons, app icons, social images, documents).

- `earmark-wordmark.svg`: tag in indigo #1A3175 with a camwood #AC4C29 eyelet, lowercase wordmark in ink #1F1B16. For light grounds.
- `earmark-wordmark-on-dark.svg`: tag in #A1BDFC, eyelet #F4B59F, wordmark #F2F0EC. For dark grounds.
- `earmark-mark.svg`: the tag alone, indigo with camwood eyelet. Favicon and small placements on light grounds.
- `earmark-mark-on-dark.svg`: the tag alone for dark grounds.
- `earmark-mark-mono-indigo.svg`: single ink, indigo #1A3175, for one-colour print and stamps.
- `earmark-mark-mono-cotton.svg`: single ink, cotton #F9F6F2, for use on indigo or photographs.
- `earmark-app-icon.svg`: full-bleed indigo square with a cotton tag inside the 80% safe zone. Maskable; export 192px and 512px PNGs from it for the web app manifest.

Clear space equals the eyelet's diameter on every side. Minimum sizes: 24px for the mark, 28px tall for the wordmark. Do not recolour, stretch, outline or add effects.
