# Icons

The 64 Phosphor icons the product uses (MIT licence, phosphoricons.com), exported single ink in ink #1F1B16 at 24px for design tools and documents. In code, use the `Icon` component, which draws the same shapes in `currentColor`.

Regular weight everywhere; the `-fill` variants are only for the active navigation item. Pocket icons: graduation-cap, bowl-food, house-line, first-aid-kit, lightning, device-mobile, bus, shopping-bag, hand-heart, piggy-bank.
