# EmptyState

What a screen shows before it has content: what belongs here and the first step.

**Provide:** `icon`, `title`, a one or two sentence body, and one `action`.

- Title says what is missing ("No pockets yet"), body says why it is useful, the action starts it.
- Family members see a different empty state: "Nothing here yet. Ṣadé will add money soon." with no action.
