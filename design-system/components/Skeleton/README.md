# Skeleton

Placeholder shapes that match the content while it loads from Arc.

**Provide:** `width`, `height`, `radius`, or `lines` for a text block.

- Mirror the real layout: a skeleton pocket card has the icon circle, two text lines, the balance block, the meter and the two buttons.
- Show skeletons only after 300ms, to avoid flashes on fast loads. The pulse stops when reduced motion is on.
