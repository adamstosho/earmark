# PocketIcon

The round icon that identifies a pocket, tinted with the pocket's hue.

**Provide:** `icon` from the pocket set, `hue`, `size` (`lg` 56px on pocket pages, `md` 44px on cards, `sm` 28px in rows).

- Each pocket keeps one hue everywhere: its icon, its meter fill and its label chip. Offer the six hues in the create form in this order: palm, sky, clay, teal, plum, olive.
- Default hues by purpose: food palm, school fees sky, rent clay, emergency teal, gifts plum, transport olive. People can change them.
