# IconButton

A 44px round button that holds one icon, for well-known actions where a word would crowd the layout.

**Provide:** `icon` and `label` (required; it becomes the accessible name and the tooltip). Pass `href` to render a link.

- Use for Back, Close, More actions, Copy, Share. Anything less familiar gets a text `Button`.
- `ghost` in app bars and rows, `secondary` when it sits beside secondary buttons, `tonal` for a highlighted tool.
- `sm` shows a 36px circle but keeps a 44px hit area.
