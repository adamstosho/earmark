# Logo

The Earmark mark is a label tag with a camwood eyelet: money that carries a label. The component draws it from `brand`, `accent` and `ink`, so it follows the theme on its own.

**Provide:** `variant` (`wordmark` or `mark`), an optional `className` to set the height.

- Use the wordmark once per screen, in the side navigation or on the landing page. Use the mark alone where space is under 120px wide, such as the navigation rail and the app icon.
- Keep clear space around it equal to the eyelet's diameter on every side. Minimum height: 24px for the mark, 28px for the wordmark.
- Write the name as **Earmark** in running text. The wordmark alone is set lowercase by design.
- Do not recolour it, outline it, add shadows or place it on photographs. On any colour other than `canvas`, `surface` or `brand`, use the single-colour files from the Logos asset group.
