# Icon

Phosphor Icons, Regular weight, drawn inline from the bundle so they inherit `currentColor`.

**Provide:** `name`; `size` (20 inside controls and rows, 24 in navigation, 16 in badges and captions); `label` only when the icon stands alone and carries meaning.

- Use the Fill weight for one thing only: the active tab in `TabBar` and `SideNav`. Everything else is Regular.
- Pair an icon with a word wherever a person must act or understand a state. Icons alone are for universally known actions (close, back, copy) and always sit inside an `IconButton` with a label.
- Pocket icons come from the pocket set: graduation-cap (school fees), bowl-food (food), house-line (rent), first-aid-kit (emergency), lightning (electricity), device-mobile (airtime and data), bus (transport), shopping-bag (market), hand-heart (gifts and giving), piggy-bank (savings).
- Never use emoji in the interface.
