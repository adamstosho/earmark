# SegmentedControl

Two to four short, mutually exclusive choices shown side by side.

**Provide:** `label` (for screen readers), `options`, `value`, `onChange`; `block` to fill the width.

- Use for choices such as the limit period (Daily, Weekly, Monthly) or Pay versus Ask. Five or more options belong in a list.
- Arrow keys move the selection, as in a radio group.
- Keep labels to one or two words.
